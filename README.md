# 📊 Adventure Works 2022 — Dashboard de Vendas

## Sobre o projeto

Este projeto consiste no desenvolvimento de um dashboard interativo utilizando **Power BI**, a partir da base de dados Adventure Works 2022.

O objetivo é explorar os dados comerciais da empresa Adventure Works e transformá-los em informações relevantes para a análise de desempenho de vendas, custos, lucratividade e outros indicadores de negócio.

O projeto está em desenvolvimento e este repositório será atualizado gradualmente, acompanhando as etapas de modelagem, criação de medidas e construção das visualizações.

## 📁 Base de dados

Os dados utilizados foram obtidos no Kaggle:

- **Fonte:** [Adventure Works in Excel Tables — Kaggle](https://www.kaggle.com/datasets/algorismus/adventure-works-in-excel-tables/data)
- **Período de referência:** até 2022.
- **Formato:** arquivos CSV organizados em tabelas.

### Sobre o conjunto de dados

O conjunto de dados Adventure Works 2022 foi disponibilizado originalmente pela Microsoft para atividades práticas de aprendizado e análise de dados no Power BI.

A versão utilizada neste projeto foi disponibilizada no Kaggle e contém arquivos CSV correspondentes às tabelas do banco de dados Adventure Works, permitindo trabalhar com os dados localmente, sem a necessidade de uma conexão com o SQL Server.


## 🛠️ Ferramentas utilizadas

- **Power BI Desktop:** modelagem de dados, criação de medidas e desenvolvimento do dashboard.
- **DAX:** criação de indicadores e cálculos analíticos.
- **Power Query:** importação e preparação dos dados.

## 📈 Análises propostas

O dashboard está sendo desenvolvido com foco na análise comercial, contemplando indicadores e perspectivas como:

- Desempenho geral das vendas;
- Receita, custos e lucro bruto;
- Margem de lucro;
- Custo médio;
- Desempenho de produtos;
- Análise de clientes;
- Evolução das vendas ao longo do tempo.

As análises e visualizações poderão ser ampliadas durante o desenvolvimento do projeto.
